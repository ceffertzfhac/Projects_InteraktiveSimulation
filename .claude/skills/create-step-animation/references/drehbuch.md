# Drehbuch-Methode

Ein Drehbuch ist eine Tabelle je Kapitel. Es wird **vor** dem Code geschrieben und dem
Nutzer gezeigt. Grundlage: `global_docs/animation_guideline.md` §1–§3.

## Kapitelstruktur

| Teil | Inhalt | Schritte |
|---|---|---|
| Einstieg | Frage + Situation (Objekt, Messgerät, Ausgangsgröße) | 1–2 |
| Erarbeitung | Vorgang zeigen → Werte ablesen → Intervalle → Grenzen → Vergleich | Hauptteil |
| Falle / Gegenbeispiel | typischer Fehler, markiert ✗, danach ✓ | 1 |
| Zusammenfassung | Vollfolie: (1) Tabelle aller Rechnungen + Beobachtung, (2) Begründung + Regel | 2 |
| Merke | Vollfolie: Regel (mit Rechenart) + ein Kasten „Beispiele“ | 1 |

Abschlusskapitel „Zusammenfassung“: je Rechenart eine Vollfolie mit Regel, Beispiel A/B,
Hinweis für Übungen und Klausur.

## Ein Schritt

| Spalte | Frage |
|---|---|
| Titel | Was ist die *eine* Aussage dieses Schritts? (erscheint in der Transportleiste) |
| Karte | Kicker · Überschrift · ≤ 3 Sätze · Formel-Kasten · ggf. Rechnerzeile |
| Bühne | Welche Handlung zeigt die Aussage? (inszenieren, nicht einblenden) |
| Halte | Wo hält der Präsentationsmodus? (`beat(tl)`) |
| hold | Auto-Play-Verweildauer (textlastig länger, 3–10 s) |

## Wo Zwischenhalte (`beat`) hingehören

Ziel ≈ 2,5–3-mal so viele Halte wie Schritte. Ein Halt, wenn der Dozent etwas **sagen**
oder die Klasse etwas **vorhersagen** soll:
- nachdem eine Situation steht und **bevor** gemessen/gerechnet wird
- je Objekt, Treffer, Messung (zweiter Stab, nächste Kombination)
- vor Intervall- bzw. Fehlerpfeilen, vor dem Zoom auf die nächste Stufe
- an der **ersten abweichenden Ziffer** eines Ziffernvergleichs (nicht dahinter)
- vor dem Sortieren / Markieren der Extreme / Entfernen des Rests
- je Zeile bzw. Beispiel in Zusammenfassungen, vor Beobachtung / Regel

Kein Halt mitten in einer zusammengehörigen Bewegung (Kamerafahrt + Teilung wachsen).

## Folienmuster (bewährt)

- **Rechnerzeile:** Symbol · „Taschenrechner:“ · Rechnung mit allen Stellen ·
  `⟶ runden ⟶` · gerundetes Ergebnis als Akzent-Plakette.
- **Grenzen:** Kasten „kleinstmöglich: … = …“ / „größtmöglich: … = …“, Ergebnisse rechtsbündig
  untereinander, abweichende Ziffern bernsteinfarben.
- **Varianten-Liste:** farbige Punkte = Treffer im Bild, Rechnung in voller Schriftgröße,
  Ergebnis fett; sortieren, Extreme markieren, Rest entfernen.
- **Falsch/Richtig:** zwei Formel-Kästen, erst ✗ mit kurzer Begründung, dann ✓.
- **Ziffernzeile:** Zählmarken über signifikanten Ziffern, Klammer „gesichert“, Pfeil
  „unsicher“, Klammer „nicht signifikant“ über führenden Nullen, Zehnerpotenz als
  „gehört zur Einheit“.
