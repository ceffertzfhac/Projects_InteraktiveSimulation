Je feiner die Zerlegung, desto schmaler das Einschachtelungsband \(O(n)-U(n)\): \(U(n) \to I \leftarrow O(n)\).
Mathematik
Zerlegung des Intervalls:
\[\Delta x = \frac{b-a}{n}, \qquad x_k = a + k\,\Delta x\]
Unter- und Obersumme:
\[U(n) = \sum_{k=1}^{n} \Big(\inf_{[x_{k-1},x_k]} f\Big)\,\Delta x\]
\[O(n) = \sum_{k=1}^{n} \Big(\sup_{[x_{k-1},x_k]} f\Big)\,\Delta x\]
Einschachtelung:
\[U(n) \;\le\; \int_a^b f(x)\,\mathrm{d}x \;\le\; O(n)\]
Integral als Grenzwert:
\[\int_a^b f(x)\,\mathrm{d}x = \lim_{n\to\infty} U(n) = \lim_{n\to\infty} O(n)\]
Mittelpunktsregel:
\[M(n) = \sum_{k=1}^{n} f\!\left(\frac{x_{k-1}+x_k}{2}\right)\Delta x\]
Hauptsatz der Differential- und Integralrechnung:
\[\int_a^b f(x)\,\mathrm{d}x = F(b) - F(a), \qquad F'(x) = f(x)\]
Gewählte Funktion und ihre Stammfunktion:
\[f(x) = 0{,}4\,x + 1 \qquad F(x) = 0{,}2\,x^2 + x\]
\[f(x) = 0{,}12\,(x-5)^2 + 1\]\[F(x) = 0{,}04\,(x-5)^3 + x\]
\[f(x) = 0{,}02\,(x-5)^3 - 0{,}3\,(x-5) + 3\]\[F(x) = 0{,}005\,(x-5)^4 - 0{,}15\,(x-5)^2 + 3x\]
\[f(x) = 2 + 1{,}5\,\sin x \qquad F(x) = 2x - 1{,}5\,\cos x\]
