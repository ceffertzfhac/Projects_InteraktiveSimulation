Physik
Je Bewegungsphase ist \(a\) konstant (\(\tau = t - t_0\)):
\[x(t) = x_0 + v_0\,\tau + \tfrac12\,a\,\tau^2\]
\[v(t) = v_0 + a\,\tau\]
Trapez-Profil einer Fahrt (Dauer \(\Delta t\), Strecke \(\Delta x\), \(r = 0{,}3\)):
\[t_{\text{acc}} = r\,\Delta t,\qquad v_{\max} = \frac{\Delta x}{(1-r)\,\Delta t},\qquad a = \frac{v_{\max}}{t_{\text{acc}}}\]
Halt: \(v = a = 0\), \(x = \text{const}\).
